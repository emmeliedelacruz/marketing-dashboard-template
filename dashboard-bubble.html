Pipeline by Channel

Two sources, and they do not agree by design. Everything above the divider is Meta-reported and attributed by Meta’s pixel — that is the only source that resolves to an ad set or an ad, so it is what every table on this dashboard uses. Everything below is Amplitude, counting users whose first touch carried that utm_source, through Bubble’s own source-of-truth events (User signed up Server → First Application Created → Free Trial created (server) → FirstSubscription) on a 30-day conversion window. Meta counts 393 signups this month; Amplitude counts 1,094 first-touch facebook signups. Different questions, different answers — do not add them, and do not read a rate across the divider.

Scale at ≥1.15× blended and ≥3 results. Pull back at ≤0.85× on ≥$100 spend.

—

Eff. is blended cost ÷ this unit’s cost for the same goal, so trials are only ever compared with trials and signups with signups. Δ vs blended is that difference multiplied by the unit’s results — the dollars this ad set saved or overspent this month against the account’s own average. It is arithmetic on real spend, not a forecast.
